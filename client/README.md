# ezQTL Client

Built with [Vite](https://vite.dev). Requires Node.js 20.19+ or 22.12+.

## Available Scripts

### `npm start`

Starts the Vite dev server at [http://localhost:3000](http://localhost:3000). Requests to `/api` are proxied to `http://localhost:3001`.

### `npm run build`

Builds the app for production to the `dist` folder.

### `npm run preview`

Serves the production build locally.

### `npm run format`

Formats source files with Prettier.
